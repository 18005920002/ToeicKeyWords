# TOEIC 词汇学习应用 — 实现计划

## Context

用户需要一个本地运行的托业词汇学习应用，用于按主题分类学习和复习托业考试词汇。应用需要支持词汇阅读（含音标、释义、例句）、生词/熟词标记，以及自定义词汇导入。

## 技术方案

**纯前端单页应用**：HTML + CSS + JavaScript，无需构建工具，双击 `index.html` 即可在浏览器中使用。数据通过 `localStorage` 持久化（生词/熟词状态）。

## 核心功能

### 1. 按主题浏览词汇
- 左侧/顶部显示主题列表（如：商务办公、旅行交通、餐饮购物、医疗健康、金融财务、通信科技 等）
- 点击主题后展示该主题下的所有词汇卡片
- 每个主题显示词汇数量和掌握进度

### 2. 词汇卡片展示
- 每张卡片显示：单词、音标、词性、中文释义、英文例句（含中文翻译）
- 卡片可翻转或展开查看详细信息
- 支持在卡片间切换（上一个/下一个）

### 3. 生词/熟词标记
- 每个词汇可标记为"生词"或"熟词"
- 默认所有词汇为未标记状态
- 可按"全部/生词/熟词/未标记"筛选
- 标记状态通过 localStorage 持久化
- 提供"只看生词"的快速复习模式

### 4. 自定义词汇导入
- 支持通过 JSON 文件导入自定义词汇和例句
- JSON 格式示例：
```json
{
  "topic": "自定义主题名",
  "words": [
    {
      "word": "example",
      "phonetic": "/ɪɡˈzæmpəl/",
      "pos": "n.",
      "meaning": "例子，范例",
      "example": "This is a good example.",
      "exampleCn": "这是一个好例子。"
    }
  ]
}
```
- 导入后追加到词汇库中，可通过界面管理

## 发音（朗读）方案

目标：例句朗读尽量接近真人自然发声。不连贯的根因有五个，逐一对应一层处理：

| 根因 | 处理 |
| --- | --- |
| 抽取稿里的 `$100, 000`、`3. 6%`、`Mr. Higgins. you must`、`U. S.`、全角标点，会让引擎硬断句、逐位念数字、逐字母拼读 | `js/tts-text.js` 的 `correct()`：构建期写入 `data.js`，导入期在内存套用，朗读前再过一次，三道入口共用一份规则 |
| 引擎默认语音可能是本地桌面语音（逐词停顿、无连读弱读） | `js/tts.js` 按名称/语言/localService 打分择优，监听 `voiceschanged` 并兜底轮询；顶部「发音」面板可手动切换、可试听 |
| 整句固定 0.8 倍速会拉长元音、破坏节奏 | 默认原速（句子 1.0 / 单词 0.95），慢速单独一档 0.72，另设全局倍率滑块 |
| Chrome：`cancel()` 后同帧 `speak()` 被静默丢弃；超过约 15 秒长句被截断 | 等引擎确认空闲再排入（延时 + 轮询）；朗读期间每 9 秒 `pause()/resume()` 续命 |
| 系统里根本没有英文语音时完全不可用 | 构建期用 `tools/gen-audio.mjs`（edge-tts，免费神经语音）预生成 mp3，运行时直接播放；美音 / 英音双轨，缺失时自动回退合成音 |

慢速优先用 `playbackRate` + `preservesPitch` 变速已生成的原速音频，语调轮廓保持不变，比重新合成一份慢速更自然。单词与例句的「连读」合并在一次会话里顺序播出，句间停顿交给引擎衔接。

所有偏好（语音、音源、口音、倍率）走 `localStorage`，应用仍是纯前端、双击可用；`audio/` 为空时功能不缺，只是自然度取决于本机语音。

## UI 设计

- 简洁清爽风格，浅色背景，适当留白
- 顶部导航栏：应用名 + 主题切换 + 筛选器
- 主区域：词汇卡片列表或单卡片浏览模式
- 生词标记用醒目的颜色标识（如橙色标签）
- 响应式布局，适配桌面和平板

## 验证方式

1. 双击 `index.html` 在浏览器中打开
2. 验证各主题词汇正常显示
3. 验证生词/熟词标记功能及持久化（刷新后状态保留）
4. 验证筛选功能（全部/生词/熟词/未标记）
5. 验证 JSON 导入功能
6. 发音：`node --check js/*.js` 无语法错；顶部「发音」面板可见语音列表且能切换；有 `audio/` 时 Network 面板出现 mp3 请求（200/206），无音频的单元回退合成音且不报错；例句原速与「慢」按钮听感不同、慢速不发闷
